How it works

Your terminal already knows. Lastout remembers.

01

Exactly what you saw

Each command's output is replayed like your terminal drew it: progress bars collapse to their last frame, colors and cursor tricks disappear, wide characters and emoji stay intact.

02

Long output, made short

3,000 lines become the head, every detected error with its context, and the tail — within a budget an AI can read. --mode full when you want everything that was recorded.

03

Secrets masked first

Recognized API keys, tokens, passwords, private keys and connection strings are redacted before anything is copied — matched on the text as your terminal showed it, so a key split by colour codes is still caught. The output of op, vault and friends is never even stored. Recordings on disk are kept as-is; the masking happens when output is read.

工作原理

终端都看见了，Lastout 都记着。

01

和你看到的一模一样

每条命令的输出，都按终端当时画出来的样子还原：进度条只留最后一帧，颜色和光标控制序列都去掉，宽字符和 emoji 原样保留。

02

再长的输出，也能变短

3,000 行变成开头、每个检测到的错误连同上下文，再加上结尾，控制在 AI 读得下的长度里。想要录下的全部内容，就用 --mode full。

03

先遮盖密钥

识别出的 API 密钥、token、密码、私钥和连接字符串，在复制之前就会被遮盖。匹配的是终端显示出来的文字，所以被颜色代码拆开的密钥也逃不掉。op、vault 这类工具的输出根本不存。磁盘上的记录保持原样，遮盖发生在读取输出的时候。

Where other tools give up

Still running, far away, or full-screen.

04

Still running? Copy it anyway

The dev server that just threw an error doesn't have to stop. ⌃⌥⌘C or lo --running copies its output so far, cleaned up like any other.

05

Over ssh, too

lssh server records every command on the remote host one by one — with nothing installed there but three small shell scripts.

06

Even full-screen programs

man, less, htop, vim: Lastout copies the last screen they showed instead of nothing.

别的工具做不到的

还在跑、在远程，或者是全屏程序。

04

还在跑？照样复制

刚报错的开发服务器不用停。⌃⌥⌘C 或 lo --running 会复制它到目前为止的输出，和别的输出一样整理好。

05

ssh 上也行

lssh server 把远程主机上的每条命令逐条记录下来，那台机器上只需要放三个小 shell 脚本，别的什么都不用装。

06

全屏程序也行

man、less、htop、vim：Lastout 复制它们最后显示的那一屏，而不是一片空白。

Privacy

Nothing goes anywhere you don't paste it.

Local only

No analytics, no account. Recordings live in a private folder on your Mac; the app connects only to check for updates, and once when you activate a license.

Redacted by default

Every copy and every agent read is scrubbed first. Agents can't turn it off.

Pause or forget

lo pause --for 30m stops recording; commands starting with a space are never stored, not even their text. Printed a password? lo forget erases that command for good.

Gone on its own

200 commands per terminal, 30 days, 500 MB — then it cleans up after itself.

Every claim above is checked against the code in the privacy policy, which also says what activating a license sends.

隐私

你不粘贴，它哪儿也不去。

只在本机

没有统计，不用注册账号。记录存在你 Mac 上的一个私有文件夹里；App 只在检查更新时联网，再就是激活授权时联网一次。

默认遮盖

每一次复制、每一次 Agent 读取，都先清理一遍。Agent 关不掉它。

暂停或忘掉

lo pause --for 30m 暂停录制；以空格开头的命令完全不存，连命令文本都不存。不小心打印了密码？lo forget 把那条命令彻底删掉。

自己清理

每个终端 200 条命令、30 天、500 MB，超出后自动清理。

上面每一条，隐私政策里都对照代码核实过；激活授权时会发送什么，那里也写清楚了。
